A chess engine in at most 4,096 bytes of Python, entered in make.fun's
"Build the strongest chess engine in 4 KB of Python" bounty. It talks to the
trial env over HTTP and searches to a fixed budget; it makes no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
